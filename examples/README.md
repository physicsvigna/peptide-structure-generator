# Examples

This directory contains input angle sets, generated PDB files, and representative images for two test conformations:

- `alpha_helix`: repeated alpha-helical backbone torsions.
- `beta_hairpin_2EVQ`: a non-idealized backbone torsion pattern derived from Model 1 of PDB 2EVQ.

The PDB files were generated with the C program in `src/proteinchain.c`.
